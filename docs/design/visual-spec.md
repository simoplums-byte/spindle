# Spindle 视觉规格

> 视觉与 token 的唯一来源。实现与本文冲突时以本文为准；要改外观，先改这里。
> 状态：v1.9（2026-11-13 定稿；同日经原型渲染校准与皮肤化，改动见 §15）
> 已确认：香槟银机身 / LCD 带曲名跑马灯 / 无封面时用 SPINDLE 丝印碟面 / 有封面时默认用专辑封面碟面 / 按键完全静态

## 1. 定调

一台放了很多年的便携 CD 机，香槟银的机身被手摸出了柔和的高光，蓝色 LCD 还亮着。它不新，也不旧得发脏——是"被认真使用过、保养得很好"的那种质感。

三条禁令：

- **不用位图纹理**。金属拉丝、镭射反光、投影全部由代码绘制，禁止贴图。摆件要在 4K 与 1x 屏上都干净，位图会毁掉这一点。
- **不用系统色与纯色底**。不出现 `.blue`、`.green`、纯白 `#FFFFFF`、纯黑 `#000000` 作为主体色。
- **不抢视觉**。它是一块屏上最安静的那个东西：没有高饱和色，没有强对比闪动，没有超过 0.12 透明度的大面积发光。

## 2. 整体几何

窗口 `344 × 344`（含 12pt 投影留白），机身 `320 × 320`，居中。

│  ┌──────────────┐   ● ● ●      │  ← LCD 176×32 @ y254

## 3. 机身

- 底色使用竖直三段渐变：`bodyTop → bodyMid → bodyBottom`，模拟顶部受光的铝合金；再叠一层横向柱面渐变（左白 10% → 中间透明 → 右黑 10%），让平面读起来是弧面的金属。
- 外侧 1pt 描边：上半圈 `bodyRimLight`，下半圈 `bodyRimDark`——用两个半圆叠加，不使用均匀描边，否则会显得像图标。
- 内阴影：顶部 2pt `bodyEdgeShadow` 30%，制造仓盖压进去的深度。
- 外投影：`y +10, blur 24, color #8B7C68 @ 30%`。这是唯一的投影，不加第二层。
- 仓盖：Ø 216 的圆形盖板，填充 `lidTop → lidBottom` 渐变（左上受光、右下入暗），外缘 1pt 由 `bodyRimLight` 过渡到 `bodyRimDark`，内缘 3pt `bodyEdgeShadow` 18% 压痕，下沿 `y+1 blur 3 @10%` 投影，让它比机身微微浮起。原型阶段先做成实心盖板——v1 的"只画细环"在实机上看起来像贴了张贴纸，见 §15。

## 4. 碟片

碟片是唯一会动的东西，三种表面必须都成立。

**A · 无封面（网易云工况，默认形态）**
银色金属底 `discBase → discInner` 沿左上到右下渐变；整面覆一层 10% 的镭射（`iridescentWashAlpha`），再在半径 62–96 的环带内叠 42% 的彩虹（`iridescentBandAlpha`）——真实光盘的彩虹集中在外圈，整张染色会立刻变成"塑料片"；然后一条 −27° 的软边眩光带（`discGlareAlpha` 16%、宽 44）斜切过碟面；叠一圈同心细环（Ø 60/110/150，1pt，白色 16%）；最后在碟面外环用丝印写 `SPINDLE`：环形排列，半径 84，字号 6，字距 2.4，颜色 `discSilkscreen` 70%。

**B · 有封面（专辑封面碟面）**
仅在碟面选择「专辑封面」时成立。专辑图填满 Ø 200 圆形区域（`scaledToFill` + 圆形裁剪），其上叠镭射层（透明度降到 14%）与径向暗角（边缘黑 18%），碟面外环 6pt 宽的银色边保留，让图片仍然像"贴"在碟上而不是铺满一个圆。选自有碟面时封面不出现，碟面回到该样式本身的观感（含圆周 SPINDLE 丝印）。

**C · 待机**
转动停止后，碟面整体透明度 0.92、镭射层透明度降到 6%——像一盏关掉了背光的机器。不隐藏碟片。

**主轴**：毂 Ø 44 用 `discHub` 径向渐变；中心孔 Ø 14 为 `discHole`，孔内加一圈 1pt 白色 10% 高光，让它看起来是"通"的。

## 5. LCD

**分区**：左侧 18pt 为状态段，右侧 150pt 为文字滚动区，中间 2pt 分隔。

| 状态 | 状态段 | 文字区 | 背光 |
| --- | --- | --- | --- |
| `.playing` + 有曲名 | ▶ | 跑马灯：`曲名 · 艺人` | 100% |
| `.playing` + 无曲名 | ▶ | 跑马灯：`NETEASE · PLAYING` | 100% |
| `.paused` | ❚❚ | `PAUSE`，静态居中；有曲名时截断显示曲名 | 100% |
| `.idle` | ○ | `STANDBY`，静态居中，用 `lcdTextDim` | 35% |
| `.unknown` | — | 保留上一次已确认状态的显示 | 上一次的背光 |

**回退阶梯（第三点的收敛结果）**：优先显示 `曲名 · 艺人`；没有元数据就显示 `来源应用 · PLAYING`；待机显示 `STANDBY`。不显示时间码——CoreAudio 通道拿不到播放位置，伪造一个跳秒的计时器是假信息，不做。想换成"留空"只改 `LCDFallback` 一个 token。

**跑马灯规则**

- 文字宽度 ≤ 文字区宽度时：不滚动，静态居中（短曲子名不该无意义地晃）。
- 溢出时：从右侧边缘入场，速度 34pt/s 匀速横移，走完尾部后停 0.9s，再从右侧重新入场。
- 只在 `.playing` 时滚动；切到 `.paused` 立刻停住并回到静态显示。
- 不使用缓动、不做淡入淡出，LCD 像素屏没有这些东西。

**质感**：背景竖直渐变 `lcdTop → lcdBottom`；文字用 `lcdText` 加 3pt 模糊的同色光晕（22%），模拟背光溢光；屏幕四周 1pt `lcdBezel` 内框 + 2pt 内阴影，做出凹陷；表面叠一条从左上到右下的白色 6% 斜向反光条，角度固定不随内容变化。

## 6. 按键与贴纸

- 三个按键（播放/上一首/下一首）**完全静态**：圆柱投影由"顶部渐变 + 底部 1pt 暗边"表现，无按压态、无 hover、无 tooltip。点击落在按键上不发生任何视觉变化。
- 窗口背景仍可拖动（拖动不属于按键交互），用于摆放位置。
- 贴纸为圆角矩形 Ø38 的圆形贴纸：纸色 `stickerPaper`，内容 `SPINDLE`（7pt 粗体，字距 1.2），下沿一行 5pt `AUDIO`；旋转 −7°，投影 `y+2 blur 4 @ 18%`。贴纸不随播放状态变化。

## 7. 状态映射

| 检测状态 | 碟片 | LCD | 时机 |
| --- | --- | --- | --- |
| `.playing` | 旋转，5.4s/圈 | 跑马灯 + 满背光 | 去抖动确认后 0.8s 内加速到全速 |
| `.paused` | 从当前角速度惯性减速，2.2s 内停住，停在当前角度 | `PAUSE` | 立即 |
| `.idle` | 静止（若从播放转入则先减速） | `STANDBY` @35% 背光 | 减速完成后 0.2s |
| `.unknown` | 保持 | 保持上一次 | 立即，不闪 |

关键约束：**暂停不做角度归位**。碟片停在它当时停下的角度，每次都不一样——这是这台机器唯一"活着"的证据。

## 10. 实现约束

- 所有 token 集中定义在 `Sources/Spindle/DesignTokens.swift`，View 内不得出现 hex、字号或时长字面量。
- 碟片旋转用角度累加 + 屏幕刷新回调驱动；**不得**使用一次性的无限 `rotationEffect` 动画（无法在中途冻结与减速）。
- 机身金属用 `LinearGradient` + 两条半圆 `stroke`；镭射用 `AngularGradient` 或线性多色 `LinearGradient` 叠在碟面上，禁止生成位图。
- 文字走系统字体，不引入自定义字体文件。
- 阴影只用一层；任何"发光"都不超过 22% 透明度。

### 菜单栏图标

用 `StatusIcon.make(status:style:)` 自绘，`isTemplate = true`，深浅色菜单栏由系统反色。基准几何：外圆半径 0.40×18pt、线宽 0.095×18pt、中心孔 0.105×18pt、高光弧 118°–198°。

选自绘而非 SF Symbol 的理由：`opticaldisc` 在 18pt 下中心的花纹糊成一个点；`opticaldisc.fill` 是一块黑饼；`record.circle.fill` 太通用，读不出"碟"。自绘线稿和 App 里的碟同源，线宽也和机身上的等高线一致。

三种状态表达（菜单栏「菜单栏图标」可切）：

| 风格 | 播放中 | 已暂停 | 待机 |
| --- | --- | --- | --- |
| `fill` 实心切换 | 盘面实心（环形挖孔） | 细环 + 中心孔 | 同暂停，alpha 0.45 |
| `badge` 角标符号 | 碟 + 右侧 ▶ | 碟 + 右侧 ❚❚ | 纯碟，alpha 0.45 |
| `spin` 转动残影（默认） | 外环留缺口 + 拖尾 | 闭合细环 + 一道弧 | 闭合细环，alpha 0.45 |

状态只在「播放 / 暂停 / 待机」之间变，`unknown` 用 0.55 alpha 表示"还没测出来"。图标每 2s 随菜单栏状态行一起刷新，仅在状态变化时才重画。

## 11. 交付自检清单

- [ ] 320pt 下丝印与贴纸文字仍可辨认，没有糊成一团
- [ ] 碟片旋转时没有频闪、没有抖动，图案不因抗锯齿闪烁
- [ ] 暂停后 2.2s 内完全停住，且停止角度每次不同
- [ ] 待机时整机明显"暗下去"，但没有变成灰色方块
- [ ] 无封面工况（网易云）下碟面依然好看，不显得像"加载失败"
- [ ] 有封面工况下图片没有撑出圆形边界，边缘仍有银色碟缘
- [ ] LCD 长曲名滚完不跳字、不重叠、不出现半截字首
- [ ] 鼠标扫过按键没有任何视觉变化
- [ ] 换一台 Retina 与一台非 Retina 检查均无位图模糊

## 12. 皮肤

同一套几何，四套配色。颜色全部收敛在 `SkinPalette`，切换只改 `Token.activeSkin`，不改布局。

| 皮肤 | 机身 | LCD | 用途 |
| --- | --- | --- | --- |
| `champagne`（默认） | 香槟银金属，暖米高光 | 深蓝底 + 冰蓝字 | 复古 Discman 初版 |
| `graphite` | 哑光石墨黑，冷灰高光 | 近黑底 + 琥珀字 | 90 年代黑色随身听 |
| `bone` | 白色塑料，全系列最亮，白色描边高光 | 深绿底 + 黄绿字 | 80 年代米白机身 |
| `steel` | 冷灰拉丝钢（96 档横纹，`blendMode .overlay`） | 近黑底 + 荧光绿字 | 台式 Hi-Fi |

共同不变量：碟片直径、镭射环带、眩光角度、跑马灯速度、按键位置与直径、贴纸尺寸与角度。

```
.build/release/Spindle --render-skins <目录>              # 一次渲染全部皮肤
.build/release/Spindle --skin graphite --render out.png   # 指定皮肤渲染单张
```

运行时切换走菜单栏「皮肤」子菜单；皮肤是全局静态值，切换后重建一次宿主视图触发重绘。


## 13. 碟面样式

碟面与皮肤正交：任何皮肤可配任何碟面，颜色在 `DiscToken`，几何仍是 `Token`。

| 样式 | 描述 |
| --- | --- |
| `albumArt`（有封面时的默认） | 当前曲目的专辑封面铺满碟面：降饱和 0.92 + 10% 白纱 + 14% 镭射，保留眩光带、导引环与银色碟缘。**只在当前曲目拿得到封面时出现在菜单里** |
| `silver`（无封面时的默认） | 银色压模 + 外圈彩虹环带 + SPINDLE 丝印 |
| `hologram` | 整盘全息干涉色（双角度彩虹叠加、紫加入色域、饱和度 ×1.35） |
| `label` | 外圈银色压模 + Ø126 米白印刷标签（顶部四色彩条 + SPINDLE / AUDIO · 74 MIN） |
| `crystal` | 半透明盘，透出 6 根辐条、压盘环、马达外壳的暗影 |
| `gold` | 暖金压模（#F6E4B8 → #D3AE63 → #8F6C36），对角光，彩虹降到 12% |
| `jibuli` | 吉卜李专属碟面：整盘只有一张画（吉卜力风人像），头部居中于盘心，无文字、丝印、导引环、轴环与中心孔 |

**选择模型**（`DiscToken.autoArtwork` + `DiscToken.active`，`effective(for:)` 求当前生效样式）：

- 默认 `autoArtwork = true`：当前曲目有封面就生效 `albumArt`，没有封面就回落到 `active`（默认 `silver`）。
- 用户在菜单里选了任一自有碟面 → `autoArtwork = false`、`active` 记住该样式，之后即使来了带封面的歌也不抢回封面碟面。
- 用户再选「专辑封面」→ `autoArtwork = true`，重新跟随封面。
- 封面消失（切到无封面的歌、待机清空元数据）时，不会留下一张上一首的封面：`albumArt` 选项同时从菜单隐藏，碟面回落到 `active`。

有真实封面时，只有 `albumArt` 把封面铺上盘面；六种自有样式一律画自己的盘面与圆周丝印，封面不参与。
`label` 不画圆周丝印（标签上已经有字）。`jibuli` 是纯图案盘，除表面眩光与边缘压暗外其余表层一律不画：中央 radial 白高光（在深色人像上糊成灰雾）、Ø60/110/150 导引环（压在脸上像划痕）、圆周丝印、Ø44 轴环、Ø14 中心孔。视觉上等于一张 picture disc，靠圆形轮廓、眩光与旋转读作光盘。

素材是预压好的 800×800 RGBA PNG（`Assets/disc-jibuli.png`，对应 Ø200pt 的 4×），运行时由 `DiscArtwork` 按 `Bundle.main` → 可执行文件上溯 `Assets/` → 当前目录 `Assets/` 三级查找；找不到就回退 `silver` 并在 stderr 报一行。素材源改用用户提供的干净版（874×874 正方形、自带均匀橙底、没有人像投影），只做一次 800×800 缩放与圆形遮罩去底，不再需要裁切与去影。构图是「胸像」：头像水平居中，发顶到下巴约占盘面直径的 40%，T 恤与大身落在下半部，靠圆形的裁切自然收边。

```
.build/release/Spindle --render-discs <目录>
.build/release/Spindle --disc gold --render out.png
.build/release/Spindle --artwork <封面图> --render out.png   # 评审带封面的碟面
```

`--render-discs` 只出六种自有碟面；`albumArt` 依赖运行时封面，不参与批量渲染。运行时切换走菜单栏「碟面」子菜单，`albumArt` 仅在当前曲目有封面时出现。

## 14. 应用图标

图标不另画一张图，直接用菜单栏那套碟片线稿的**闭合细环版**（`spin` 的暂停/待机态，不带转动残影），保证 App 内外是同一个符号。

**几何**（画布 1024×1024，比例式定义，任意尺寸重算）

| 项 | 值 |
| --- | --- |
| 圆角板 | 内缩 8.2%，即 ≈824；圆角 22.5% 板宽 |
| 投影 | 黑 25%，blur 4.5% 边长，偏移 y −1.8% 边长 |
| 底板 | 竖直三段渐变 + 上半区 22% 白高光 |
| 描边 | 0.45% 边长 |
| 外环 | 半径 30.5% 板宽，线宽 4.0% 板宽 |
| 中心毂 | 半径 8.2% 板宽，线宽 2.6% 板宽 |
| 高光弧 | 半径 = 外环 − 10% 板宽，118°–198°，线宽 2.0% 板宽 |

**配色**：四套方案，同一张线稿只换底与线色。默认 `graphite`（v1.9 定稿）。

| 方案 | 底板（上→下） | 线稿 | 取向 |
| --- | --- | --- | --- |
| `champagne` | `#F8F2E8 → #D3C8B4 → #AFA28C` | `#5A5145` | 与机身同族，最像这台机器 |
| `graphite`（默认） | `#45454A → #35353A → #1E1E22` | `#F2EADA` | 深底亮线，浅色 Dock 上轮廓最清楚 |
| `lcd` | `#0B2A38 → #061A24` | `#7FD8FF` | 取 LCD 的蓝，冷、安静 |
| `steel` | `#DCE0E3 → #B3B8BC → #84898E` | `#3E444A` | 冷银底 + 深墨线，工业感最强 |

```
.build/release/Spindle --render-app-previews <目录>          # 四套配色对照图 + 单张
.build/release/Spindle --icon-scheme graphite --render-app-icon <iconset 目录>
```

`scripts/build-app.sh` 每次构建都会重渲染 `AppIcon.iconset` 并用 `iconutil` 打成 `Contents/Resources/AppIcon.icns`，`Info.plist` 里 `CFBundleIconFile = AppIcon`。改配色只需改 `AppIconScheme`（或改默认值），不需要手工准备图片。

## 15. 变更记录

### v1.9（2026-11-13，应用图标）

- **菜单栏图标默认改为「转动残影」**。`fill` 在 18pt 下播放态是一块挖孔黑饼，在深色菜单栏里比残影更容易被看成"加载中"。风格仍可切。
- **应用图标复用菜单栏线稿**，取 `spin` 的闭合细环态，不新画符号；四套配色方案，定稿 `graphite`（石墨黑底 + 暖白线），对照图见 `docs/design/renders/appicon/`。
- **图标由构建生成**：`build-app.sh` 调 `--render-app-icon` 出 `AppIcon.iconset`，`iconutil` 打成 `AppIcon.icns`，`Info.plist` 挂 `CFBundleIconFile`。没有手工 PNG 资产，改配色只改 `AppIconScheme`。
- **修掉 `Info.plist` 的闭合标签错误**：`LSMinimumSystemVersion` 之前写成 `<string>14.0</key>`，`plutil` 报 "Close tag on line 12 does not match open tag"。系统一直容忍，但图标这类需要严格解析的字段迟早出问题。

### v1.8（2026-11-13，专辑封面碟面）

新增第七种碟面 `albumArt`，并把它设为"有封面时的默认"：Apple Music 工况下打开就是在转一张印着这张专辑的盘，不用再手动选。

- **封面从"覆盖一切"改为"一种碟面"**。v1.2 起只要 `NowPlaying.artwork` 非空就无条件铺满盘面，六种样式实际只有眩光强度不同。现在封面只在 `albumArt` 生效，自有碟面画自己的盘面与 SPINDLE 丝印——手选吉卜李或金碟之后，来一首带封面的歌也不会被顶掉。
- **无封面时隐藏选项**，而不是留一个灰掉的项。菜单里出现「专辑封面」这件事本身就是"这首有封面"的信号；拿不到封面的歌（网易云、无封面曲目）菜单里就只有六种自有碟面。
- **回落不留残影**。切换曲目时若新曲目没有封面，元数据层旧封面必须一起清掉，否则会拿上一首的封面继续转。检测层因此在曲目键变化但导出失败时把 `artwork` 置空。
- **默认值**：`autoArtwork = true`、`active = silver`。因此无封面时看到的仍是"银色压模 + SPINDLE 丝印"，与 v1.2 的默认观感一致。

### v1.7（2026-11-13，吉卜李碟面）

第六种碟面 `jibuli`，把用户自己的卡通形象印成一张专属盘。素材不走 View 里的矢量合成，而是预压一张 800×800 PNG 进 `Assets/`，`build-app.sh` 顺手拷进 `Contents/Resources/`。

三处渲染问题逐个修，都是「在银色盘上没问题、印到图案上就露馅」的那类：

- **中央 radial 白高光（endRadius 90）在深色人像上糊成一块灰雾**。图案类碟面（`jibuli` / `label`）不再画这层。
- **Ø44 实心轴环在人像上是一块灰斑**。改为只留一圈 25% 白 + 外圈 10% 黑的细亮边，保留"有轴环"的暗示但不遮图。
- **人像被中心孔切脸**。先试"标签盘 + 圆形人像"，孔始终落在盘心，怎么移都会压到下巴；改成"满版插画 + 头像上移"，孔又压到胸口、读起来像挂着吊坠。
- **终版按用户要求改成纯图案 + 头像居中**：整盘只有一张画，文字（「吉卜李」弧字与 `SPINDLE · PRIVATE PRESSING` 小字）、两道奶白细环、轴环、中心孔全部去掉；原图按正方形裁切、以头像中心对齐盘心。既然不画孔，"孔必落在五官上"的矛盾也就不存在了。
- **背景投影**：旧源图右侧有一道人像投影，会跟着碟一起转、读起来像脏污，先按用户意见做过一次低频提亮；后来用户直接提供了没有投影的干净版，这一步随之取消，素材只保留缩放与圆形遮罩。
- **导引环压在脸上像划痕**、**圆周丝印会和人像打架**：`jibuli` 一律不画。

`--render-discs` 现在出六张，对照图改由 `scripts/make-disc-contact-sheet.py` 生成 3×2 版式。

### v1.2（2026-11-13，检测接通后）

- **LCD 文案改为按状态分阶梯**：待机 `■ STANDBY` / 暂停 `II PAUSE`（有曲名时显示 `曲名 · 艺人`）/ 播放且有曲名 → `曲名 · 艺人` / 播放且无曲名 → `▶ NETEASE · PLAYING`（来源名跟随实际播放器）。所有播放器都取不到曲名时仍不显示时间码。
- **跑马灯只在该滚的时候滚**：文案装得下就居中静止，装不下才以 34pt/s 滚动，起步前停 0.9s；滚动时首尾留 0.75×可视宽度的空白，避免两段文字首尾相接。
- **真实封面可直接印上碟面**：封面按圆裁切铺满 Ø200，饱和度降到 0.92、盖 10% 白雾，让彩虹带与眩光仍然显形；有封面时不画圆周丝印，避免文字压在画面上。
- **窗口落到鼠标所在屏**：多显示器下不再跟随"焦点屏"。
- **投影改由窗口系统绘制**：原来在 320 机身内部画 24pt 投影，被 344 的窗口边界裁掉，外圈就剩一道紧贴轮郭的暗环。改为 `hasShadow = true`，投影由合成器画在窗口之外，边缘柔和、不裁切。
- **机身可拖动**：SwiftUI 宿主视图会吃掉鼠标按下事件，改为 `DraggableHostingView` 把事件交给窗口做 `performDrag`。
- **新增 `BROWSER` 来源**：网页出声时 LCD 显示 `▶ BROWSER · PLAYING`，碟面用丝印。浏览器不参与暂停/待机判定。

### v1.1（2026-11-13，原型校准）

首版渲染出来后逐项校准，改动均来自"实机上看着不对"而不是凭感觉调色：

- **仓盖从细环改为实心盖板**。v1 只画一圈 1pt 细环，渲染出来像贴在机身上的一张圆形贴纸，机身与碟片之间没有层次。改为 Ø216 渐变盖板 + 压痕 + 微投影后，才有"盖着一层壳"的实体感。
- **镭射从整面染色改为外圈环带**。整面 22% 镭射会把碟片染成紫粉色，看起来像塑料玩具。真实光盘的彩虹集中在外圈，改为 10% 整面 wash + 半径 62–96 的 42% 环带。
- **增加斜向眩光带**。原本碟面只有柔和的金属渐变，缺少"一眼认出是光盘"的高光，补了一条 −27°、16% 白的软边眩光。
- **碟面丝印改为深灰**。白色丝印在银色碟面上几乎不可见，改用 `#575C63` 70%，像真的丝印油墨。
- **贴纸字号下调**。7pt + 1.2 字距在 Ø38 圆内会把 SPINDLE 挤成两行，降到 6pt + 0.8 后单行成立。
- **机身补柱面高光**。纯竖直渐变读起来像陶瓷，加了横向左右明暗后才有金属弧面感。
